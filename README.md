## 📌 نبذة عن المشروع (Overview)

نظام **DIEMS** هو منصة رقمية متكاملة ومؤتمتة أُعدت لـ **مؤسسة المعارض والأسواق الدولية السورية (SEIFE)** للتحول الرقمي الكامل في إدارة وتشغيل **معرض دمشق الدولي**. يقدم النظام بدائل رقمية للعمليات اليدوية والورقية التقليدية، ويوفر بيئة تنظيمية وتفاعلية تخدم أربعة أطراف رئيسية: الزوار، الشركات العارضة، أصحاب الفعاليات، وإدارة المعرض.

---

## 🎯 أهداف المشروع (Key Objectives)

* **أتمتة إدارة المعرض بالكامل**: الاستغناء عن التعاملات الورقية في حجز المعارض وتخصيص الأجنحة والتذاكر.
* **تسريع حركة الزوار بالبوابات**: إصدار تذاكر رقمية مشفرة بـ QR Code والتحقق منها فورياً لمنع الازدحام والتزوير.
* **حل مشكلات التضارب والحجز المزدوج**: استخدام آليات قفل ذرية برمجية لمنع تعارض مواعيد الفعاليات والأجنحة.
* **توفير تحليلات لحظية لمصممي القرار**: تزويد الإدارة ببيانات وإحصاءات لحظية حول أعداد الزوار وإشغال القاعات المتاحة.

## 🏗️ بنية المنظومة والأنظمة الفرعية (Subsystems Architecture)

يتكون نظام **DIEMS** من أربعة أنظمة فرعية متكاملة ترتبط عبر واجهة خلفية مركزية (RESTful API):

1. **تطبيق الزوار (Visitor Mobile App - Flutter)**:
   * تصفح المعرض ودليل الشركات بدون الحاجة لتسجيل دخول.
   * خريطة تفاعلية قابلة للتحريك والتكبير لعرض القاعات والتنقل إليها.
   * حجز التذاكر المدفوعة عبر بوابة دفع إلكترونية وتوليد رمز QR فريد.
   * تخزين التذاكر المحجوزة محلياً (SQLite) للوصول إليها بدون إنترنت.
   * استعراض جدول الفعاليات اليومي ومعلومات خطوط النقل والمواصلات.

2. **بوابة ويب الشركات وأصحاب الفعاليات (Exhibitors Portal - React.js)**:
   * تقديم طلبات مشاركة الشركات عبر نموذج متعدد الخطوات مع إرفاق رخص العمل والمستندات.
   * إدارة الملف الشخصي للشركة وإدخال المنتجات والعروض الترويجية.
   * استكمال عمليات الدفع المالي الإلكتروني لمستحقات الأجنحة المحجوزة.
   * تقديم مقترحات الفعاليات مع تزامن التقويم في الوقت الفعلي عبر WebSockets.

3. **لوحة تحكم الإدارة (Admin Dashboard - React.js)**:
   * مراجعة وإدارة طلبات مشاركة الشركات وتخصيص الأجنحة الآلي والتجميعي.
   * موافقة/رفض الفعاليات مع **الرفض التلقائي للطلبات المتعارضة** باستخدام **Redis Atomic Locks**.
   * إدارة أنواع التذاكر وأسعارها ومراقبة مبيعاتها وإيراداتها لحظياً.
   * نظام CMS كامل لتحرير محتوى المعرض، وإدارة الشكاوى، والمستخدمين والصلاحيات.
   * إدارة النسخ الاحتياطي التلقائي المشفر وتخزينه على **AWS S3**.

4. **واجهة بوابة الدخول والتحقق (Gate Entry Interface - Flutter / React.js)**:
   * شاشة مسح بملء الشاشة لرموز QR مخصصة لموظفي البوابات.
   * مصادقة رقمية رمزية تتجدد يومياً لضمان سلامة وأمان المنظومة.
   * استجابة مرئية فورية (أخضر: مسموح | أصفر: مستخدمة مسبقاً | أحمر: غير صالحة).
   * إعادة تعيين تلقائية خلال 3 ثوانٍ لمعالجة التدفق المرتفع للزوار.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| المكون (Component) | التقنية (Technology) |
| :--- | :--- |
| **Backend API Framework** | Laravel 11.x (PHP 8.2+) |
| **Authentication & Auth** | Laravel Sanctum |
| **Primary Database** | PostgreSQL 16 |
| **Caching & Queue Processing** | Redis 7.x & Laravel Horizon |

| **Web Frontends** | React.js 18.x (Vite) |
| **Mobile & Gate Apps** | Flutter 3.x / Dart 3.x & SQLite |

## 🔐 الأمان والموثوقية (Security & Performance)

* **التشفير وحماية البيانات**: كافة اتصالات الـ API تعمل عبر بروتوكول HTTPS، مع تشفير كلمات المرور باستخدام bcrypt.
* **حماية من الحجز المزدوج**: اعتماد **Redis Atomic Locks** لمنع تضارب إنتاج التذاكر أو تعارض حجز الفعاليات.
* **حماية رمز QR**: يحتوي الـ QR على رمز مبهم فريد (UUID) خالٍ من أي بيانات شخصية ذات صلة بالهوية.
* **التعافي والنسخ الاحتياطي**: نسخ احتياطية يومية آلية مع إصدار روابط تنزيل مؤقتة مشفرة عبر AWS S3 Pre-signed URLs.
